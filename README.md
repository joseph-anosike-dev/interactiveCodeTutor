# Interactive Code Tutor

Create a simple web app that can be used as an interactive ui vanilla js react teacher with a code runner added to each lesson separated by tabs

Nothing fancy just the basic functionality, mostly black and white with dark red accent and very little gold trims

This project was built with [Lovable](https://lovable.dev).
